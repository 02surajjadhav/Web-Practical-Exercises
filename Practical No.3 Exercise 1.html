Web Development Lab

This page demonstrates how to link an external CSS file and apply different colors and font properties to style a webpage.

About This Exercise

The goal is to separate content (HTML) from presentation (CSS) by using an external stylesheet named style.css. This makes the code cleaner and easier to maintain.

Features Used

  • External CSS file linked with the <link> tag.
  • Custom font families and sizes.
  • Different text and background colors.
  • Styled headings, paragraphs, lists, links, and images.
